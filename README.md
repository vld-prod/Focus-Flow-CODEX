# FOCUS FLOW

Личное пространство для задач, времени и осмысленного дня. Готовое статическое приложение на **HTML5, CSS3 и Vanilla JavaScript**. Никаких фреймворков, npm, сборки, ключей API или серверной логики. Приложение не загружает внешние шрифты, изображения, скрипты или библиотеки.

## Возможности

- Обзор дня: актуальная дата, приветствие, выполненные и оставшиеся задачи, дневной прогресс, серия продуктивных дней, время фокуса и недельная активность.
- Задачи: создание, редактирование, удаление с подтверждением, выполнение и отмена, описание, категория, дата, время, приоритет, плановая длительность, поиск, комбинируемые фильтры, сортировка и перетаскивание на компьютере.
- Pomodoro: настраиваемые рабочие сессии и перерывы, старт/пауза/продолжение/сброс, привязка к задаче, кольцевой индикатор, звуковой сигнал, уведомления браузера. После четырёх рабочих сессий предлагается длинный перерыв. Следующая сессия запускается вручную.
- Календарь: месяцы, задачи по датам, выбранный день, кнопка возврата к сегодняшнему дню и создание задачи на выбранную дату.
- Аналитика: реальные завершения задач и сессий за последние 7 или 30 дней, время фокуса, активные дни и распределение всех задач по категориям.
- Настройки: имя, светлая/тёмная тема, длительность циклов, дневная цель, звук, запрос разрешения на уведомления, экспорт/импорт JSON, удаление демоданных и полный сброс с подтверждением.
- LocalStorage, синхронизация вкладок одного браузера, проверка импортируемой схемы и безопасный вывод пользовательского текста.
- Адаптивная компоновка от 320 px, мобильная нижняя навигация, клавиатурное управление, нативные диалоги с удержанием фокуса и поддержка `prefers-reduced-motion`.

## Публикация на GitHub Pages — без сборки

1. Распакуйте архив и создайте репозиторий на GitHub.
2. Загрузите **содержимое** папки `focus-flow` в корень репозитория: `index.html` должен лежать непосредственно в корне, рядом со `styles.css` и папкой `js`.
3. Откройте **Settings → Pages → Build and deployment**.
4. Выберите **Deploy from a branch**, ветку `main` и папку **/ (root)**. Нажмите **Save**.
5. Дождитесь успешной публикации GitHub Pages и откройте адрес `https://ваш-логин.github.io/имя-репозитория/`.

Все пути относительные, переходы используют `#hash`. Приложение работает в подпапке репозитория без переписывания URL. Файл `.nojekyll` отключает ненужную обработку Jekyll. GitHub Actions, Node.js и установка зависимостей не нужны.

Для разработки можно использовать любой статический HTTP-сервер или функцию Live Server редактора. Например, при установленном Python: `python -m http.server 8000` из папки проекта. Это только способ локального просмотра. На GitHub Pages Python не используется. Открытие `index.html` через `file://` не поддерживается из-за политики браузера для ES-модулей.

## Управление и данные

- **N** — новая задача, если фокус вне поля ввода.
- **Ctrl+K / ⌘K** — поиск задач.
- **Escape** — закрыть диалог; **Tab / Shift+Tab** — перемещение по элементам.
- **← / → / Home / End** — переключение вкладок списка на экране обзора.
- Редактирование открывается нажатием на название задачи. В списке всех задач доступны отдельные кнопки удаления и перехода к фокусу.
- Сортировка «Мой порядок» позволяет менять порядок перетаскиванием на компьютере. На телефоне используйте обычные способы сортировки.
- Даты задач трактуются как **местные календарные даты**, без сдвига через UTC. Серия учитывает дни с завершёнными задачами или рабочими сессиями; вчерашняя серия сохраняется, пока сегодняшний день ещё не завершён.
- При первом запуске создаются демонстрационные задачи и сессии, помеченные как демоданные. Статистика рассчитывается из этих записей, затем — из ваших действий. Удалить их можно в настройках. Изменённые и отмеченные вами демонстрационные задачи становятся вашими.
- Экспортируйте JSON в настройках для резервной копии и переноса на другое устройство. Импорт **заменяет** текущие данные только после подтверждения. До импорта сохраните резервную копию.

## Ограничения

Данные привязаны к браузеру и адресу сайта. Очистка хранилища браузера удалит их; автоматического облачного резервирования нет. Не переносите приватные данные в публичный GitHub-репозиторий: JSON-экспорт хранится отдельно от исходников.

Закрытая вкладка не может воспроизвести звук или показать уведомление. При возвращении таймер пересчитывается по временной метке и завершает просроченную сессию один раз. Браузер также может отложить звук и уведомления в замороженной фоновой вкладке. История остаётся корректной. Для системных уведомлений нужны HTTPS, поддержка браузера и выданное пользователем разрешение; сообщения внутри приложения работают всегда.

Автоматические проверки выполнены в Chromium. Отдельные прогоны в Safari, Firefox и на физических устройствах не выполнялись. Подробности — в `docs/QA.md`.
